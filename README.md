# Unit-тесты геометрических фигур

Четыре модуля библиотеки, четыре файла тестов и отчёт `REPORT.md`.

Запуск из папки проекта:

```bash
python3 -m unittest discover -v
```

Отдельный модуль:

```bash
python3 -m unittest -v test_circle
```

В 34 методах проверяются 326 наборов данных. Примеры записаны в списки и перебираются циклом с `subTest`, поэтому провал одного примера не останавливает остальные.

Результат: 179 проверок прошли, 147 провалились. В итоговой строке `Ran 34 tests` указано число методов. Причины провалов описаны в отчёте. Исходные функции не изменены. Дополнительные пакеты не нужны.
