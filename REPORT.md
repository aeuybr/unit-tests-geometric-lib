# Отчёт по лабораторной работе № 5

## Знакомство с CI/CD

### Цель работы

Настроить автоматический запуск unit-тестов геометрической библиотеки при каждом `push` в GitHub. Проверка должна выполняться на двух системах: Ubuntu и Windows.

### Workflow

Файл `.github/workflows/main.yml` запускается при событии `push`. В job используется матрица с runner'ами `ubuntu-latest` и `windows-latest`. На каждом runner GitHub Actions получает исходный код, устанавливает Python 3.12 и выполняет:

```bash
python -m unittest discover -v
```

Команда автоматически находит тестовые файлы `test_*.py` в корне проекта.

### Проверяемый проект

В работе используются четыре набора тестов из предыдущей лабораторной: `test_circle.py`, `test_square.py`, `test_rectangle.py` и `test_triangle.py`. Всего в них 34 тестовых метода и 326 проверяемых примеров.

В ходе предыдущей лабораторной тесты выявили ошибки в функциях библиотеки. В этой версии проекта исправлены найденные ошибки: формулы периметра прямоугольника и площади треугольника, а также проверки некорректных размеров. Файлы лабораторной работы № 4 оставлены без изменений.

### Результат

Локальный запуск `python3 -m unittest discover -v` завершился успешно: все 34 тестовых метода выполнены, статус — `OK`. Результат автоматического запуска на GitHub Actions приведён на скриншоте в конце отчёта.

### Вывод

Добавлен workflow GitHub Actions для автоматического запуска unit-тестов при каждом `push`. Тесты запускаются на Ubuntu и Windows с Python 3.12.
